# 把 Claude 腔说成人话

Claude 写的中文带着一股助手腔：开口先捧、说完必总结、一个意思解释三遍、句尾挂客套。这一段的活是把这股腔拆掉，留下平实的中文。输入可以是 Claude 直接产出的稿子，也可以是用户手上任何一篇带这种腔调的中文。

先认出它。Claude 腔常见的样子：

- 开口先捧：「这是个好问题」「你提到的情况确实很常见」。
- 先垫后说：「让我们一起来看看」「简单来说」「需要注意的是」。
- 对话残留：「希望这个回答对你有帮助」「如果你需要，我可以再展开讲讲」「有什么我可以帮你的吗」。稿子不是对话，这些全是废话。
- 结尾必总结：「总的来说」「综上所述」，然后把说过的话复述一遍。
- 解释癖：一个意思说三遍——先说结论，再解释一遍，再举个例子，其实一遍就够。
- 列表癖和加粗癖：能写成句子的非要拆成 ①②③，三行一个加粗小标题。
- 翻译腔：「在某种程度上」「对于……来说」「通过……来……」。

改写的规矩只有几条，借自那个仓库的内置 prompt，是它真正有效的部分：

- 用日常的词，写短句子。能一个词说清的不用三个。
- 每个事实、名字、数字、文件路径原样保留，一个不许丢。
- 代码块、命令、标识符一个字不动。
- 保持原文的人称视角，别把「我」和「你」换位。
- 只输出改写后的正文，不加前言，不解释改了什么。

和第二段的分工：稿子的模板句式、套话、拔高骨架归 deai-rewrite 管，这一段专拆助手腔。两段可以连跑——先 ② 拆模板，再 ④ 去对话腔；稿子哪种病更重就先跑哪段。

边界和其他段一样：只动语言，不动信息。改完把数字、专名、文件名对着原文数一遍，少了就还原那句。本来就不带腔的稿子，原样返回。
