## 2. schema v1.0 映射

脚本：`/Users/mac/claudeclaw/humanize/data/prepare_nlpcc2025.py`

映射严格输出 N1 schema v1.0 的 26 字段：

- 固定字段：`schema_version="1.0"`，`source="nlpcc2025_task1"`，`source_url` 指 GitHub repo，`license="unknown-research-only"`，`license_url` 指 README `#data-restriction`。
- 时间窗：按任务要求填 `time_start="2024-01-01"`，`time_end="2025-12-31"`。
- label：0→`human`，1→`ai`。
- model：train 的 `gpt4o/glm/qwen/human` 分别映射为 `gpt-4o/glm-4-flash/qwen-turbo/null`；test AI 按 README 推断 `deepseek-v3`；dev 缺模型，保留 null 并在 notes 标注 `model=missing`。
- register/genre：CNewSum→`news/news_report`，CSL→`academic/abstract`，ASAP→`blog_essay/blog_post`；test→`creative_longform/story`；dev 缺 source，按关键词和长度粗判。
- prompt：train 用 `ASAP/CNewSum/CSL`；test 用 `STORAL`；dev 无 prompt 时为 null。
- normalize：`cn_norm_v1`，NFKC、折叠空白、去控制字符/HTML、保留简繁和段落。
- PII：手机号、邮箱、身份证、微信/QQ 强模式 redact；银行卡/地址组合进入 pending review。本轮无 pending review。
- 去重：先 `sha256(normalized_text)` 精确去重，再用 char 5-gram SimHash64，按 train→dev→test 顺序保留首个 split，跨 split 后出现的重复丢弃。

| --- | ---: | ---: | --- |
| general | 0.852 | 0.919 | `cross_para_3gram_repeat +3.46`，`sent_len_cv -1.99`，`news_vs_human +1.95`，`wiki_vs_primary -1.36`，`sent_len_equal_mid_frac +1.33` |
| academic | 0.913 | 0.859 | `perplexity -2.01`，`sent_len_cv -1.43`，`news_vs_human +1.24`，`bino_lp_diff -1.11`，`trans_density +1.08` |

解释：NLPCC train 的 300-800 字样本占绝对多数，且 ASAP/CSL/CNewSum 的 AI 写法很模板化。它确实提升了训练 holdout，并让 HC3 gap 微升，但对 runtime humanizer 的 hero 输出形成了过强的“模板/段落/句长”惩罚。Longform LR 更危险，因为 NLPCC train 没有 STORAL/DeepSeek creative longform；把短中篇 train 样本硬加进 longform 会造成场景错配。

替换实验 B 未继续跑。理由是 A 没有正向：correct 降低，hero trip wire 破坏明显；按任务定义，B 只在 A 正向时做比例 sweep。

## 6. 合入建议

结论：**skip 当前 1:1 合入，不替换 runtime coef。**

推荐使用方式：

- NLPCC 可进入私有实验池和 N7 ablation，但不要作为 general/longform 的直接高权重追加训练源。
- 若继续 sweep，先做 scene-gated：CSL 只给 academic 候选，CNewSum 只给 news/general 候选，ASAP 不直接喂 longform；train/dev 不混用，dev 只做 tuning/diagnostic。
- test/STORAL/DeepSeek-V3 只适合作 holdout/OOD eval 或单独 longform 诊断，不应进入训练。
- 比例从极低权重开始：`NLPCC:existing = 0.1:1`、`0.25:1`，并加 hero hard gate；当前 1:1 权重过高。
- 对 AI 侧按 model family stratify，避免 GPT-4o/GLM/Qwen 的统一模板特征被 LR 误学成泛化规则。

## 7. N5 / N7 建议

N5 synthetic frontier：用 C-Eval/CMMLU/真实 prompt seed 自跑 frontier synthetic 时，必须保留 prompt_id、model_family、生成日期和 register，且每个 register 单独配 human 对照。NLPCC 可提供 frontier 旧窗口的 reference distribution，但不应替代自跑 frontier 数据。

N7 one-corpus ablation：建议把 NLPCC 拆成四个独立切片：`CSL_academic`、`CNewSum_news`、`ASAP_review_blog`、`STORAL_test_eval_only`。每个切片单独跑 LR 加权曲线、HC3、hero、longform benchmark，再看是否只合入某个 scene 的低比例样本。当前全量混合的结论是“有检测信号，但会伤 runtime 改写目标”。
