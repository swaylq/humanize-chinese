### P1#4 `_pick_lr_scene` routing

- `scripts/humanize_cn.py` 新增 `_count_chinese_chars()`，使用与 `ngram_model._auto_scene()` 一致的 CJK 范围：`'\u4e00' <= c <= '\u9fff'`。
- `_pick_lr_scene()` 改为使用中文字符数阈值 1500，不再使用 raw `len(text)`。
- academic/longform 冲突采用“长文优先”：
  - `CJK >= 1500` -> `longform`
  - `academic markers >= 2` -> `academic`
  - else `general`
- regression test 增加：
  - 短中文 + 2 学术 marker -> academic。
  - >1500 CJK 无 marker -> longform。
  - >1500 CJK + 2 marker -> longform。
  - 500 CJK + 1500 ASCII/Markdown -> general。
